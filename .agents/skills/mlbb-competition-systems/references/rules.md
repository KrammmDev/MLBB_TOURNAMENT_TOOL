# Competition rule inventory
For each supported draft format record phase sequence, acting side, action, count, timer defaults, unique-hero restrictions, correction/swap policy and end condition. Derive current settings from both dropdown scripts; do not assume latest MPL rules.

For series record best-of, wins required, side choice and reset identity. For tournaments record tie breakers, manual-rank precedence, seeding, byes, group qualification, elimination flow and grand-final reset. Define behavior when an earlier result is corrected after downstream play.

For statistics distinguish game pick rate (games featuring hero / eligible games), ban rate (games banning hero / eligible games), pick share (hero picks / all picks) and win rate (hero wins / hero picks). Choose and label the intended metric; existing code is not an approved specification. Handle zero denominators and incomplete imports explicitly.
