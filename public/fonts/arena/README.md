# Arena display fonts

Bundled Latin webfonts served locally for offline OBS use:

- **Russo One**, weight 400: https://fonts.google.com/specimen/Russo+One
- **Oxanium**, variable weights 400–800: https://fonts.google.com/specimen/Oxanium

WOFF2 files were downloaded from Google Fonts' Latin CSS responses. Each accompanying OFL file comes from the corresponding family in https://github.com/google/fonts/tree/main/ofl. Preserve these license files when distributing the fonts.

Arena uses Russo One for display headings and Oxanium for labels, team names, scores and the timer. These are geometric/esports alternatives, not the exact font families shown in the user's reference image. Unsupported glyphs use the CSS fallback fonts.
